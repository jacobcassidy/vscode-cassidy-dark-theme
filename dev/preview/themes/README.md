# Generated development themes

This directory contains development themes generated from the authored inputs in `src/themes/dev/`. Run `npm run build:dev` to rebuild them. The local Cassidy Dark Preview extension loads these files for checking theme changes in VS Code; edit the source inputs rather than these generated files.

After removing or renaming a source theme, build and watch automatically remove its obsolete JSON output if its first line is `// Generated by npm run build:dev. Edit the corresponding inputs and rebuild.`. Removed paths appear in blue with `(removed)` in terminal output. The header is the ownership marker even if the generated body was edited. Files without the matching header are preserved and block the build. `npm run check:generated` reports pending removals without deleting files.
