# v1.3-beta-dev theme differences from v1.2

Comparison of the [v1.3-beta-dev theme](../../../preview/snapshots/cassidy-dark-color-theme-v1.3-beta-dev.json) with the [v1.2 snapshot](../../../preview/snapshots/cassidy-dark-color-theme-v1.2-prod.json).

“Inactive” means absent or commented out in the compared file; it does not imply that VS Code has no default or that another selector cannot supply styling. Descriptive comments, formatting, metadata, and scope ordering within an unchanged rule are excluded. Commented-out properties and rules are considered when identifying activations.

For `tokenColors`, entries are compared by exact scope selector and setting (`foreground` or `fontStyle`), rather than by array index or rule name. A selector moved to a different color rule is listed as a value change. Duplicate selector assignments and settings on empty-scope rules are called out separately.
