# Static theme snapshots

This directory contains preserved theme JSON files used as fixed references when comparing theme changes. They are static artifacts and are not regenerated by the theme build. Add or update a snapshot deliberately when a comparison baseline should change.

To override a snapshot's parenthetical label, add an optional top-level property such as `"previewName": "Baseline 1.3"`. The development extension then registers it as **Cassidy Dark Snapshot (Baseline 1.3)**. Without this property, the suffix comes from the filename. A supplied value must be a nonempty string after trimming; capitalization is preserved and duplicate preview labels are rejected. Run `npm run build` after changing the value, or leave `npm run watch` running to sync it automatically. Follow the cyan reload reminder when the registration changes.
